# Default software development workflow

For requests to build software projects or implement features, use the user-level `speckit-full-cycle` skill by default. Read `C:/Users/AD/.codex/skills/speckit-full-cycle/SKILL.md` and follow its nine stages: constitution -> specify -> clarify -> plan -> checklist -> tasks -> analyze -> implement -> converge.

Continue between stages automatically; ask only for material missing information or permissions actually required. Reuse an established constitution and resume existing feature artifacts. Follow the user's requested scope, including explicit instructions for a shorter workflow. Questions, reviews, documentation-only edits, installation/configuration tasks, and small isolated fixes do not automatically require the full cycle unless the user requests it.
